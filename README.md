## CODEQUEST

CodeQuest is a gamified coding learning platform that helps users learn and practice programming through interactive challenges, MCQs, and AI-powered assistance.

## Features

- User Authentication: Allows users to securely register and log in.
- Coding Challenges: Enables users to practice programming through coding tasks.
- MCQ Module: Provides coding-related MCQs to strengthen theoretical knowledge.
- Gamification: Uses points, levels, and progress tracking to motivate users.
- AI Chatbot: Helps users with coding-related doubts and guidance.
- Code Execution: Executes submitted code securely using the Judge0 API.
- Admin Module: Allows administrators to manage users, questions, and tasks.

## Tech Stack

- Frontend: Flutter, Dart
- Backend: Node.js
- Database: Firebase, Firestore
- Code Execution: Judge0 API
- AI: AI Chatbot
